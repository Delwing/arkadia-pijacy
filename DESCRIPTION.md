# Podpowiedzi emotek Klubu Pijakow

Podpowiedzi dla emotek Klubu Pijakow. Wpisz poczatek komendy i wcisnij
**Tab** - plugin dopelni ja do pelnej emotki.

## Co potrafi

- **Dopelnianie Tabem** - `pis` + Tab daje `pistuknij`, `pip` + Tab
  przelacza miedzy `pipochwal`, `pipotrzasnij` i `pipodnies`.

## Instalacja

1. W menedzerze pluginow Arkadia Web Client dodaj plugin **Podpowiedzi emotek Klubu Pijakow**.
2. Wpisz `pi` i wcisnij Tab, zeby sprawdzic, czy dziala.

## Prywatnosc

Plugin nic nie zapisuje i nie wykonuje zadnych zapytan sieciowych.
